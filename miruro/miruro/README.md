# Miruro plugin

Anime-only catalog and stream resolution for SkyStream.

## Sources

- **AllAnime** — primary catalog and episode stream API.
- **Jikan** — anime-only MAL catalog/search/detail fallback.
- **Kitsu** — JSON:API anime catalog fallback.
- **HiAnime API** — optional self-hosted `/api/v2` adapter for catalog, episodes, and sources.
- **AniList + AniZip** — detail and episode metadata enrichment.

Manga, manhwa, manhua, comic, novel, and other non-video records are filtered out before mapping.

## Files

- `plugin.json` — manifest. Schema validated by `skystream validate`.
- `plugin.js` — bundled source-aware plugin implementation.
- `.build/plugin.bundled.js` — generated by `skystream deploy`; do not edit by hand.

## Testing

```bash
npm run test:unit
skystream validate
skystream test -p . -f getHome
skystream test -p . -f search -q "naruto"
```

Episode URLs use a versioned JSON envelope such as
`{"v":2,"source":"allanime","id":"...","episode":"1","dubStatus":"sub"}`.
Legacy AllAnime `{hash, episode, dubStatus}` payloads remain readable.
