# Miruro plugin

Anime catalog + stream resolution for SkyStream.

## Files

- `plugin.json` — manifest. Schema validated by `skystream validate`.
- `plugin.js` — the actual plugin. Single IIFE, no dependencies.
- `.build/plugin.bundled.js` — generated by `skystream deploy`. **Do not edit by hand.**

## Endpoints used

See [`../docs/API.md`](../docs/API.md).

## Testing

```bash
skystream test -p . -f getHome
skystream test -p . -f search -q "naruto"
```
